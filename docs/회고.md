## 8단계 — 테스트 · Sepolia 배포 · 화면 연결

재료
- 테스트 27개, 리뷰 중복 검사 한 줄을 빼면 C4 가 실패
- 개인키를 `.env` 에 넣지 않고 MetaMask 서명으로 배포. Faucet 하루 1번 → 계정끼리 나눠 씀

- 화면에서 서명 전에 결제를 미리 확인 → 수수료 낭비 방지. 배포된 Pages 에서 첫 리뷰 제출, 포인트 90 → 100

## 10단계 — AI 오라클

재료
- 오라클이 점수에 서명, 컨트랙트가 확인 → T1 해결. 서명에 체인 · 컨트랙트 · 결제 · 사람 · 내용 해시를 넣어 재사용 · 바꿔치기 차단 (테스트 F3~F6)
- OpenZeppelin 최신은 cancun(mcopy) 필요 → Hardhat · Remix 둘 다 EVM 설정

- 배포된 컨트랙트의 서명 해시를 직접 불러 오라클과 같은지 확인
- 오라클은 판정을 위조 못 하게 할 뿐 정확하게 만들지는 않는다
