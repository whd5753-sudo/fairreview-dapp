# 커밋 메시지 규칙
1. `git diff --staged` (비어 있으면 `git diff`) 로 바뀐 내용을 먼저 본다.
2. 형식: `N단계: 무엇을 했는지 (왜)` — 한 줄, 50자 안팎.
3. 여러 일을 했으면 가장 중요한 하나만 제목에 쓰고, 나머지는 빈 줄 뒤 목록으로 쓴다.
4. .env 나 키 파일이 staged 되어 있으면 커밋하지 말고 경고한다.
5. 메시지는 제안만 하고, 실제 커밋은 사용자가 확인한 뒤에 한다.
