# 기대값 표 — AI ① 문장 판정 (4단계)

코드보다 **이 표를 먼저** 정했다. 테스트는 이 표를 그대로 옮긴 것이고, 테스트가 실패하면 **코드를 고치지 표를 고치지 않는다.**

## 규칙

| 규칙 | 조건 | 점수 |
|---|---|---|
| 광고·대가성 문구 | 아래 목록 중 들어 있는 **패턴 수** = 건수 (패턴마다 한 번만 셈) | 1건 이상이면 450 + 100 × (건수 − 1) |
| 과장 표현 | 아래 목록 중 들어 있는 **단어 수** | 3개 이상이면 120 + 40 × (개수 − 3) |
| 매우 짧은 극단 평점 | 글자 수 < 10 이고 별점이 1 또는 5 | +150 |
| 구체성 없음 | '매우 짧은 극단 평점'이 아니고, 구체성 = 0 이고, 글자 수 < 40 | +100 |
| 구체적 경험 보너스 | 구체성 = 2 이고 글자 수 ≥ 30 | −80 |
| 최종 점수 | 합계를 0 ~ 1000 사이로 자른다 | |

- **글자 수**: 앞뒤 공백을 지우고, 남은 글에서 공백 문자를 모두 뺀 글자 수
- **광고 패턴** (정규식): `협찬` `체험단` `원고료` `소정의` `제공\s*받` `무료로\s*(제공|받)` `리뷰\s*이벤트` `이벤트\s*참여` `서비스\s*받고` `쿠폰\s*(받|주)` `별점\s*5\s*(개|점)\s*(주면|드리면)` `광고`
- **과장 단어**: 최고 · 강추 · 대박 · 인생맛집 · 무조건 · 완전 · 존맛 · 레전드 · 미쳤 · 꼭 가세요 · 강력 추천 · 역대급 · 짱 · 갓
- **구체성** (0~2): ① 숫자가 있으면 +1 ② 경험 단어(`메뉴|주문|시켰|먹었|국물|면|밥|고기|커피|디저트|가격|양이|웨이팅|주차|직원|사장님|자리|매장|포장|배달|맛이|간이`) 중 하나라도 있으면 +1

## 판정 (decide)

| 점수 | 판정 | 이유 |
|---|---|---|
| 0 ~ 399 | 게시 | |
| 400 ~ 699 | 보류 | 확신이 없으면 지우지 않고 사람이 본다 (진짜 손님 보호) |
| 700 이상 | 거부 | 확신이 높을 때만 자동 거부 |
